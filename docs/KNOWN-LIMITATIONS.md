# Current limitations — Build 006

- Artwork remains original procedural/placeholder SVG, pending owner art direction, difficulty playtesting, commercial review and physical proofs. The new editor supports composition; it does not complete the detailed commercial illustration standard.
- Five primary puzzle mechanics are implemented. No secondary mechanics are claimed. Difficulty primarily changes maze dimensions; route deduction is a clue-code gate activity, the library OAK key is an explicit completion reward, and the final cipher uses a full key.
- Functional activity blocks are protected whole puzzles. Cells, routes, start/finish and individual clue positions remain generator-controlled. Maze line weight is editable. Moving/scaling a block does not change its solution. One principal activity is supported per page.
- Grouping associates selection/movement rather than nested scene transforms. Basic left/top alignment and horizontal distribution are provided. Puzzle grids remain independent from page layout grids. There is no full desktop-publishing constraint solver.
- Imported SVGs use a strict primitive subset: no live SVG text, CSS, scripts, external resources or colour. Convert lettering to outlines. Raster import produces a thresholded monochrome icon mask at up to 160 cells, suitable for simple icons rather than high-detail illustration. SVG is preferred for finished artwork.
- Six character placeholders have one standing pose. Pose/expression/role/clue metadata is available for Build 007; modular anatomy, expression rendering, character bibles and pose libraries are not implemented. Isometric/panoramic scene authoring and Build 008 world tools remain future work.
- Projects, reusable assets, queue records and recoverable canvas drafts are device/origin-local. There is no shared cloud database, cross-device sync or collaborative editing. Browser quotas apply. Download committed project JSON for backup. History is capped at 30 snapshots / approximately 600 KB.
- Desktop mouse drag-and-drop and tablet tap-to-add are supported, with pointer dragging and inspector alternatives. Native HTML library drag-and-drop is primarily a mouse workflow. Arbitrary screen DPI depends on display calibration; Actual print size uses 96 CSS pixels/inch.
- PDF exports are capped at 40 pages per package, with a 2 MB server request bound. Very large imported asset sets may require smaller packages. Visual pages use saved trim/bleed settings and preview DPI; legacy pages use the Publishing profile. Custom trim sizes still need a printer-specific proof.
- The original five-page sample is below KDP minimum book length. Automatic layout checks and rights records do not constitute publication approval or legal clearance.
- Paid generation remains disabled. No direct Story Book Builder import has been verified. Existing source-export handoff remains available. No unrelated application or DNS change was made.
- The host runs Node 24.11.1 while the installed cf CLI declares 24.22+ or 22.23+. Builds/tests/deployment work here; upgrade Node for the CLI-supported baseline.

- Cloudflare returned one transient 1102 resource-limit response during overlapping live export checks. Isolated and bounded three-request retries succeeded; no CPU/memory root cause was established from the short profile. The client retries transient failures once. Avoid overlapping large exports and use a smaller package if the platform continues reporting a resource limit. No paid plan upgrade was initiated.
